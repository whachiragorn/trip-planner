# 🇨🇳 Shanghai Trip 2026 · แผนเที่ยวเซี่ยงไฮ้

เว็บแอปพลิเคชันสำหรับวางแผนและจัดการทริปเที่ยวเซี่ยงไฮ้ 16–20 ธันวาคม 2026

## ✨ คุณสมบัติเด่น
- ✈️ **เที่ยวบิน & ที่พัก:** ตารางบินไป-กลับ (FM842 / MU547), ข้อมูลโรงแรมพร้อมชื่อภาษาจีน
- 🗓️ **ไทม์ไลน์รายวัน (Day 1 - 5):** กิจกรรมพร้อมเวลา, โน้ตการเดินทาง, พิกัด Amap, ลิงก์รีวิว TikTok
- 🇨🇳 **ชื่อภาษาจีน & ปุ่มคัดลอก (📋 คัดลอก):** มีชื่อจีนทุกสถานที่ กดคลิกเดียวเพื่อนำไปค้นหาใน Amap หรือเรียก Didi
- ✏️ **แก้ไขข้อมูลได้ผ่านหน้าเว็บ:** ปรับเวลา, เพิ่ม/ลบ/ย้ายกิจกรรม, สลับวัน หรือย้ายไปไอเดียสำรอง
- 💰 **คำนวณงบ & ค่าใช้จ่าย:** บันทึกค่าใช้จ่ายระหว่างทริป (หยวน/บาท) และสรุปยอดค่าใช้จ่าย
- ☁️ **ซิงค์ข้อมูลร่วมกัน:** เมื่อเปิดผ่านเซิร์ฟเวอร์ การแก้ไขจะบันทึกรวมกันที่ `trip.json` แบบเรียลไทม์

## 🚀 วิธีเปิดใช้งานภายในเครื่อง (Local)
```bash
# รันเซิร์ฟเวอร์
python3 server.py 8000
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

## ☁️ วิธี Deploy ขึ้น Render.com (ฟรี)
1. สมัครใช้งานที่ [render.com](https://render.com)
2. กด **New +** -> **Web Service**
3. เชื่อมต่อกับ Repository นี้
4. ตั้งค่า:
   - **Environment:** `Python 3`
   - **Start Command:** `python3 server.py`
5. กด **Deploy Web Service**
